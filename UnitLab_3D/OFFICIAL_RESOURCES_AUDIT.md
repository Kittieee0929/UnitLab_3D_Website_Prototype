# UnitLab 3D — Actual Learning Materials Audit

**Re-reviewed:** October 26, 2026  
**Project:** UnitLab 3D CBAR — Computer Hardware Servicing

This document replaces the earlier resource audit. The previous version contained direct PDF URLs that could not be opened or verified and DepEd catalog entries that merely *described* a file. Those entries have been removed from the website's Resources section **and from the in-lesson links**. The sources below were located with a substantive, readable document or viewable presentation page.

**Access classifications**

- **PDF:** the original URL serves or is indexed as an actual PDF document with accessible source text/pages. Opening it may still depend on the publisher's access controls or browser.
- **Presentation:** a real SlideShare deck with individually numbered, readable slides; viewing is possible on the page. **Downloading is not guaranteed to be free and may require a SlideShare/Scribd account.**
- **Manufacturer tutorial:** a real page containing step-by-step instructional material, not a downloadable PDF.
- **Third-party:** independently uploaded, not a verified DepEd or TESDA instructional publication. Always cross-check against current safety guidance.

## Explicitly removed from the learner-facing resources

**Never silently reintroduce these links as downloadable study PDFs until someone has actually opened the underlying file:**

- Direct DepEd CG URL `https://www.deped.gov.ph/wp-content/uploads/2019/01/Computer-Systems-Servicing-NC-II-CG.pdf`: automated fetch **403**, not independently opened as PDF.
- Direct DepEd course URL `https://www.deped.gov.ph/wp-content/uploads/Computer-Systems-Servicing.pdf`: automated fetch **403**, not independently opened.
- Assumed LAS05 / LAS09 / LAS25 / LAS26 PDF URLs: did not yield a readable file during verification (403, unexpected response or cache miss).
- DepEd `lrmds.deped.gov.ph/detail/...` catalog listings: **metadata pages**, not direct PDF lessons. Useful for provenance but fail the request for immediately viewable learner materials.
- `deped.gov.ph/ligtas-aral/` landing page: a collection/index, **not a downloadable lesson itself**.

This is a conservative, availability-focused shortlist. Some removed URLs may still work in a normal browser, but they were not independently verified here and therefore were excluded.

## Where materials appear in UnitLab 3D

- **Resources tab:** searchable cards, filterable into Presentations / PDF documents / Practical guides, with correct source and access labels.
- **Every Learning Module:** up to 8 reviewed sources placed immediately below the module's learning competency. PDF cards include an optional preview iframe and a direct source link. Presentations open on SlideShare in a new tab (no invented embed URLs).
- **Teacher lesson-plan references:** formerly catalog-only IDs were replaced with links in this verified resource set.
- **Do not** describe independently uploaded SlideShare items as officially approved DepEd modules or claim they are free downloads.

### Research note

These external materials are supplementary reading and presentation references. They do **not** replace UnitLab 3D's independently authored intervention and approved CBAR assessment procedures. The project does not mirror source material or store official student assessment data.
