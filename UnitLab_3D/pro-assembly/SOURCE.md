# UnitLab 3D · Pro Assembly Simulator

The simulator in this folder is adapted from [Prism Forge](https://github.com/carlomigueldy/three-pc-builder-simulator) by Carlo Miguel Dy (2026), used under the MIT License. The required copyright and permission notice is retained in [LICENSE-PRISM-FORGE.txt](LICENSE-PRISM-FORGE.txt).

## Integration

This copy replaces the upstream Vite bundle setup with a browser import map for Three.js 0.160.1, enabling static hosting on GitHub Pages. The original Three.js procedural scene, hitboxes, assembly state, compatibility scoring and build animations are preserved. UnitLab provides the top navigation and a disclaimer.

**Scope:** An interactive visual training engine—not manufacturer CAD, actual consumer prices or TESDA-certified assessment. All showcased hardware choices, wattage/performance labels and prices originate in the upstream demo catalog and must not be presented as confirmed retail facts. The separately developed UnitLab PC Builder remains the place for a sourced part-selection and compatibility exercise.

To update this copy: review the source project's MIT license and its changes, then port deliberately; it is not configured to download updates automatically.
